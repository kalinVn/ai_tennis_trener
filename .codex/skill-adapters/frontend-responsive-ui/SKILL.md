# Frontend Responsive UI

Read `../../../claude/skills/frontend-responsive-ui.md`, `../../../claude/rules/frontend/frontend-design-system.md`, and the applicable responsive requirements/prototypes.

Preserve one design language, practical controls, readable content, modal/table/navigation usability, media aspect ratios, and no unintended horizontal overflow. Training must retain safe camera/video behavior on small screens.

Use existing tokens and breakpoints where supported. Run representative viewport and keyboard/accessibility checks and report actual results.
