# Frontend Code Architect

Read repository-root `.codex/references/frontend-architecture.md` and every source it selects for the current concern. Also read repository-root `docs/frontend/frontend-project-structure.md`.

Inspect real code and similar systems before proposing changes. Assign one owner per authoritative state/resource, keep dependencies narrow and directional, distinguish simple component families from complex local feature systems, and avoid a frontend `modules/` layer or hypothetical abstractions.

Follow review-only versus implementation scope from the user's request.
