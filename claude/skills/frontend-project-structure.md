# Frontend Project Structure Reference

Read `docs/frontend/frontend-project-structure.md`. It is the single source of truth for the frontend project structure.

Inspect the existing code before creating files and do not define a second structure in this compatibility reference.

Current page, route, and shared-versus-feature ownership comes from `docs/frontend/frontend.md`, `docs/frontend/pages-and-routes.md`, and `docs/frontend/components.md`. Do not restore removed pages such as Progress from `claude/PROJECT_STRUCTURE.md` or older examples. `FeatureCard` is feature-owned production UI even though its visual prototype remains grouped with prototype cards.
