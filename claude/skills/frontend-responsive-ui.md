# Frontend Responsive UI

## Purpose

Ensure the frontend works across supported screen sizes.

## Rules

Design mobile-first where practical.

Verify:

- navigation
- forms
- dashboards
- cards
- training controls
- camera preview
- overlays
- billing UI
- dialogs

The Training experience must preserve the camera aspect ratio.

Controls must remain usable without covering critical video content.

Avoid fixed dimensions unless they are genuinely required.
