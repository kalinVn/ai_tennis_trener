# Home Page Video Slider

`HomePageVideoSlider.vue` owns all DOM refs and passes their elements to a `SliderController` instance. The component calls `await sliderController.init()` followed by `sliderController.play()` on mount, displays initialization errors in its Vue error element, and calls `sliderController.destroy()` on unmount. All runtime classes remain local to this directory:

- `SliderController.js`: owns the renderer, video controller, lifecycle and motion tracking panel, coordinates async initialization and playback, and tears down the instance. `init()` validates all required elements before creating resources and propagates errors to Vue. `play()` only starts the initialized slider; destruction is idempotent.
- `AIMotionTrackingPanel.js`: owns the existing Phase field and rotates illustrative statuses every 2.5 seconds, independently of video pauses, analysis and seeks. `SliderController.play()` starts its single interval after successful initialization; `destroy()` clears it. Mode and Overlay remain static; no measurement fields are added.
- `SliderConfig.js`: authored freeze annotations, coaching messages, timing, and overlay constants.
- `PixiRenderer.js`: owns the Pixi Application and Graphics/Text overlays, responsive cover mapping, and renderer cleanup. `preparePlayerParameters()` measures geometry and clears the frame; `drawSegment()` and `drawLabel()` draw prepared state, and `render()` displays the stage. `clearPlayerParameters()` removes the overlay. There is no segment iteration or animation timing in the renderer. It does not control playback or browser lifecycle.
- `VideoTimelineController.js`: owns the main GSAP `videoTimeline`, built by `createVideoTimeline()`, and coordinates `AudioTimeline` and `PlayerAnalysisTimeline` through their public APIs. `init()` configures the video and creates paused main/audio timelines; analysis is created only when needed. `play()` starts playback and audio. Explicit pause points at `timelineItem.time / playbackRate` call `onVideoPause()`, which pauses video and the main clock and starts analysis. Completion calls `onVideoResume()`, clearing annotations and resuming video and the main clock. The main clock covers 15 seconds of playback; the two analysis holds add 9 seconds to the cycle.
- `AudioTimeline.js`: owns the repeating coaching clock, sentences, typing and microphone UI. Five equal 4.8-second slots cover the 24-second cycle: 3.3 seconds for a sentence and 1.5 seconds for `...`. Typing uses 55ms per character, accelerated only if necessary to fit. Its `play()`, `pause()` and `destroy()` manage its own GSAP timeline. Pause preserves the currently displayed UI. Audio timing never consults freeze state.
- `AnimationTimeline.js`: owns one GSAP timeline per position, with one tween per segment at `index * lineStepMs / 1000`, lasting `lineDrawMs / 1000`. GSAP animates progress and label alpha; it prepares line endpoints and orchestrates one cleared/redrawn Pixi frame per update. `play()`, `pause()`, `resume()`, `clear()` and `destroy()` control the animation. `play()` returns the GSAP timeline for composition into the analysis phase.
- `PlayerAnalysisTimeline.js`: owns the analysis phase and its `AnimationTimeline`. It nests the drawing sequence at time zero, holds the final annotations for the remaining configured duration, then clears them and completes. Pausing the parent freezes its drawing sequence too. Destruction releases both timelines.
- `SliderLifecycle.js`: only reports video errors and calls the video controller's `pause()` on error. An AbortController removes its error listener on destruction. It has no visibility, resize, seeking, readiness or buffering listeners, observers, or automatic playback control. `SliderController.play()` directly calls `videoController.play()` after initialization; browser visibility and reduced-motion settings no longer gate playback through this class.
- `slider.css`: preserved presentation and active-state CSS animations.

Playback remains 0.3×, with holds at 2.9s for 5.5s and 3.7s for 3.5s, sequential 350ms line starts and 300ms line drawing. No service/composable or actual microphone recording is involved. Values are authored demo annotations, not computer-vision measurements.

Home uses this component under Vite; static HTML previews retain their Canvas fallback with the same independent sentence schedule and ellipsis gaps. All use the single local WebM in this directory’s `assets/`. Destroy is idempotent, including while async Pixi initialization is pending; event listeners, all GSAP timelines, the motion panel interval, media playback and renderer resources are released.
